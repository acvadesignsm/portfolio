# Портфолио — Софья Михайлова

Статичный сайт: `index.html` + `styles.css` + `script.js` + папка `assets/`. Сборка не нужна — откройте `index.html` в браузере.

## Что осталось сделать

1. Положите своё резюме в `assets/career-summary-section/resume.pdf` (кнопка «скачать резюме»).
2. В `index.html` найдите `TODO` и подставьте ссылку на VK.

## Картинки

Код использует вашу структуру папок `assets/` (hero-section, projects-section, about-section, career-summary-section, contact-section). Если переименуете файлы, поправьте пути в `index.html` / `case-magazine.html`.

## Блок «Мой опыт»

- «показать больше ↗» раскрывает запись целиком: «Проблема», «Решение» и остальные проекты этой работы (текст из раскрытого макета). Повторный клик сворачивает.
- Две левые колонки (компания/даты и должность) при прокрутке раскрытой записи едут вместе с текстом (`position: sticky` у `.exp-row__who` и `.exp-row__role`). Не нужно — удалите этот блок в `styles.css`.

## Анимации

В `script.js` и разделе «анимации» в `styles.css`: вход главной при загрузке, появление блоков при прокрутке, плавающие украшения, ховеры, каскад при раскрытии опыта. При включённом в системе «уменьшить движение» анимации отключаются.

## Страница кейса

- `case-magazine.html` + `case.css` + `case.js` — кейс «Печатный журнал…». Картинки в `assets/projects-section/projects-section-case/case-vinul/`. Добавленные мной производные папки: `web-vinul/` (webp для быстрой загрузки), `video-vinul/` (сжатые видео), `magazine-print.pdf` (PDF журнала — открывается по кнопке «Посмотреть журнал»).
- Первая карточка на главной ведёт на неё (кликабельна вся карточка).
- Кейс содержит все 7 разделов, липкую панель «все проекты / разделы» и таймлайн за два дня.
- В конце кейса ссылка «Посмотреть журнал» пока ведёт на `#` — вставьте адрес в `case-magazine.html` (ищите `TODO`).
- Большие картинки (карта журнала, мудборд, типы страниц) открываются по клику.
- Чтобы сделать новый кейс — скопируйте `case-magazine.html`, поменяйте тексты и картинки и укажите ссылку в `.card__go`.
